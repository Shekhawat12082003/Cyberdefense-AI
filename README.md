# CyberDefense-AI

CyberDefense-AI is a defensive security monitoring and analysis project with separate SOC and ransomware-analysis workspaces. Its architecture, database schema, model behavior and confidence semantics, data flows, setup, API, limitations, and report-writing material are documented in the single project dossier: **[read.md](read.md)**.

Use [read.md](read.md) as the primary source when preparing a semester report. It distinguishes implemented behavior from optional integrations, synthetic simulations, metadata-reported model scores, and limitations; do not present model confidence as calibrated real-world probability.
